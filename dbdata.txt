# LMS Database Tables & Fields

This is your CURRENT planned LMS database architecture.

The hierarchy is:

```txt id="’winitw8"
Users
→ Courses
   → Modules
      → Lessons
      → Quizzes
         → Questions
```

---

# 1. `profiles`

Main LMS user table.

Connected to Supabase Auth.

## Purpose

Stores:

* admins
* students
* instructors
* LMS-specific user info

---

## Fields

| Field      | Type      | Description                  |
| ---------- | --------- | ---------------------------- |
| id         | UUID      | Same as `auth.users.id`      |
| name       | TEXT      | User full name               |
| email      | TEXT      | User email                   |
| role       | TEXT      | admin / student / instructor |
| status     | TEXT      | active / blocked             |
| avatar_url | TEXT      | Profile image                |
| bio        | TEXT      | User bio                     |
| created_at | TIMESTAMP | Account creation             |
| updated_at | TIMESTAMP | Last update                  |

---

# 2. `registration_requests`

Pending student approval requests.

---

## Purpose

Students request access here.

Admin approves/rejects.

---

## Fields

| Field            | Type      | Description                   |
| ---------------- | --------- | ----------------------------- |
| id               | UUID      | Request ID                    |
| name             | TEXT      | Student name                  |
| email            | TEXT      | Student email                 |
| password_hash    | TEXT      | Hashed password               |
| status           | TEXT      | pending / approved / rejected |
| approved_by      | UUID      | Admin who reviewed            |
| approved_at      | TIMESTAMP | Approval/rejection time       |
| rejection_reason | TEXT      | Optional rejection reason     |
| requested_at     | TIMESTAMP | Request creation time         |

---

# 3. `courses`

Top-level LMS entity.

---

## Purpose

Stores course metadata.

---

## Fields

| Field         | Type      | Description                    |
| ------------- | --------- | ------------------------------ |
| id            | UUID      | Course ID                      |
| title         | TEXT      | Course title                   |
| slug          | TEXT      | URL-friendly course slug       |
| description   | TEXT      | Course description             |
| thumbnail_url | TEXT      | Course thumbnail               |
| price         | NUMERIC   | Course price                   |
| level         | TEXT      | beginner/intermediate/advanced |
| category      | TEXT      | Course category                |
| published     | BOOLEAN   | Is course public               |
| created_by    | UUID      | Admin/instructor ID            |
| created_at    | TIMESTAMP | Creation time                  |
| updated_at    | TIMESTAMP | Last update                    |

---

# 4. `course_modules`

Modules/chapters inside course.

---

## Purpose

Groups lessons and quiz.

---

## Fields

| Field       | Type      | Description        |
| ----------- | --------- | ------------------ |
| id          | UUID      | Module ID          |
| course_id   | UUID      | Parent course      |
| title       | TEXT      | Module title       |
| description | TEXT      | Module description |
| position    | INTEGER   | Module order       |
| created_at  | TIMESTAMP | Creation time      |
| updated_at  | TIMESTAMP | Last update        |

---

# 5. `lessons`

Actual learning units/videos.

---

## Purpose

Stores lesson content.

Usually:

```txt id="’winitw9"
1 lesson = 1 video
```

---

## Fields

| Field       | Type      | Description              |
| ----------- | --------- | ------------------------ |
| id          | UUID      | Lesson ID                |
| module_id   | UUID      | Parent module            |
| title       | TEXT      | Lesson title             |
| description | TEXT      | Lesson description       |
| video_url   | TEXT      | Video URL                |
| content     | TEXT      | Notes/article content    |
| duration    | INTEGER   | Video duration (seconds) |
| position    | INTEGER   | Lesson order             |
| is_preview  | BOOLEAN   | Free preview lesson      |
| created_at  | TIMESTAMP | Creation time            |
| updated_at  | TIMESTAMP | Last update              |

---

# 6. `quizzes`

Quiz metadata.

---

## Purpose

Quiz for module assessment.

---

## Fields

| Field           | Type      | Description        |
| --------------- | --------- | ------------------ |
| id              | UUID      | Quiz ID            |
| module_id       | UUID      | Parent module      |
| title           | TEXT      | Quiz title         |
| description     | TEXT      | Quiz description   |
| pass_percentage | INTEGER   | Passing percentage |
| time_limit      | INTEGER   | Quiz time limit    |
| created_at      | TIMESTAMP | Creation time      |
| updated_at      | TIMESTAMP | Last update        |

---

# 7. `quiz_questions`

Stores actual parsed CSV questions.

---

## Purpose

Quiz questions/options/answers.

---

## Fields

| Field          | Type      | Description        |
| -------------- | --------- | ------------------ |
| id             | UUID      | Question ID        |
| quiz_id        | UUID      | Parent quiz        |
| question       | TEXT      | Question statement |
| options        | JSONB     | Array of options   |
| correct_answer | TEXT      | Correct answer     |
| points         | INTEGER   | Marks for question |
| created_at     | TIMESTAMP | Creation time      |

---
